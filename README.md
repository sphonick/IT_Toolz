# IT_Toolz

Small, self-contained sysadmin scripts. Each tool lives in its own directory
with its own README and has no dependencies outside what ships with the OS.

| Tool | Platform | What it does |
|------|----------|--------------|
| [`windows/WindowsUpdateGuard`](windows/WindowsUpdateGuard) | Windows 10/11 | Un-pauses Windows Update at every boot, and helps find whatever keeps pausing it |
